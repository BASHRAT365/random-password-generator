# Random Password Generator

A responsive random password generator built with HTML, CSS and JavaScript.

## Features

- Generate random passwords instantly
- Adjustable password length
- Include uppercase letters
- Include numbers
- Include symbols
- Copy password to clipboard
- Input validation
- Responsive design
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Live Demo

https://bashrat365.github.io/random-password-generator/

## Project Structure

random-password-generator/
├── index.html
├── style.css
└── script.js

## How It Works

The user can choose the password length and select
different character options.

JavaScript then generates a random password based
on the selected options.

The generated password can also be copied to the
clipboard with one click.
